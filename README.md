# Athletic AI website

Static site: `index.html`, `styles.css`, `main.js`, and `assets/`. No build step.

## Run it

From this folder, run one of these, then open http://localhost:8000

```
python3 -m http.server 8000
```

```
npx serve -l 8000 .
```

You can also just double-click `index.html`.

## Edit

- Copy and sections: `index.html`
- Colors and fonts: the top of `styles.css`
- Booking email: search `gavinrtodd15@gmail.com` in `index.html`
- Logo files: `assets/` (transparent cuts of the original logo)

## Deploy

Upload the whole folder to any static host (Vercel, Netlify, GitHub Pages).
